# Lifebase

Small, fast, accessible apps. Built with care, shipped with nothing extra.

## How we build

- **Accessibility is the architecture, not a feature.** WCAG 2.2 AA is the floor, not the ceiling. Visual, audio, haptic, and screen reader channels carry the same experience.
- **Zero dependencies on the client.** No frameworks, no build steps, no third-party scripts, no tracking. The source you read in DevTools is the source that runs.
- **One purpose per app.** Each app does one thing completely rather than many things partially.
